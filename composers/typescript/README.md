# TypeScript composer

- [`core`](core/) (`@client-compose/composer`): framework-agnostic composer.
- [`node-http`](node-http/) (`@client-compose/node-http`): `node:http` adapter, plus this repo's conformance server (`conformance-server.ts`) and a runnable `example.ts`.

Run the tests from the repo root with `pnpm test` (includes composer conformance over HTTP).
