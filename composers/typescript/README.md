# TypeScript composer

Tier: **core** · Protocol: **v0** · Node 24+ (runs TypeScript directly; no build step yet)

- `core` (`@client-compose/composer`): `defineIsland`, `defineScreen`, `createComposer`, and
  `composeHttp` for adapters. `defineIsland(ProfileHeaderV2, resolve)` takes a descriptor
  generated by `codegen/`.
- `node-http` (`@client-compose/node-http`): adapter for `node:http`, plus a conformance server
  and a runnable `example.ts`.

Writing an adapter for another framework (Express, Fastify, Hono, Lambda...) means: route
`POST /screens/:screen`, read the raw body, call `composeHttp(compose, screen, body, ctx)`, and
write `result.status` / `result.body` as JSON. See `node-http/src/index.ts` (about 20 lines).

## Tests

```sh
pnpm test   # from the repo root; runs composer conformance over HTTP
```
